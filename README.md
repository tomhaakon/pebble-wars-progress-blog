# 11-09-26 UI Improvements

A pass on the game's book-styled windows: the NPC dialogue book got small
readability fixes, and the player's Character/Skills/Quests/Settings windows
were merged into a single book that matches its look exactly.

## NPC Dialogue Book

![Katla's dialogue menu](images/11-09-26/Skjermbilde%202026-09-12%20004628.png)

 The book's bookmark ("×") sits at the top, tucked into the
page like a real bookmark, instead of floating as a plain round button.

![Handing in "Prove You'll Last"](images/11-09-26/Skjermbilde%202026-09-12%20004636.png)

Turning in a quest now shows just the flavor text and a "Complete Quest".
## The Player Book

Character, Skills, Quests, and Settings used to be separate windows with
inconsistent styling. They're now four bookmarked tabs of one shared boo.,

![Character tab](images/11-09-26/Skjermbilde%202026-09-12%20004641.png)

The Character tab arranges the equipment slots as a proper paper doll (Head
alone, then Cape/Chest, Legs/Belt, and Main/Off Hand paired up) on the left
page. The right page toggles between **Stats** and a **Viewer** for the
portrait, instead of cramming both onto one crowded page.

![Skills tab](images/11-09-26/Skjermbilde%202026-09-12%20004644.png)

Skills keeps its two-page layout - disciplines and training progress on the
left, learned abilities on the right - now reskinned in the same parchment
look as everything else instead of its old dark-green panel.

![Settings tab](images/11-09-26/Skjermbilde%202026-09-12%20004647.png)

The old Escape-key popup is gone - Settings is just another tab now, reachable
the same way as the others.
